# 객체 탐지 비교 대시보드

한 장의 이미지에서 COCO 사전학습 Faster R-CNN ResNet-50-FPN과 팀의 Lite R-CNN v3가 찾은 객체, 경계 상자, 단일 이미지 추론 시간을 비교한다. 모델 출력은 실제 추론 결과이며, 두 모델에 동일한 이미지와 640px 설정을 사용한다.

## 준비

- Python 3.10 이상 및 서로 호환되는 PyTorch, torchvision, Pillow가 필요하다. 저장소 루트에서 `python -m pip install -e .`로 프로젝트 의존성을 설치할 수 있다. CUDA를 사용하려면 장치와 드라이버에 맞는 PyTorch·torchvision을 별도로 설치해야 한다. 설치 방법은 [PyTorch 공식 안내](https://pytorch.org/get-started/locally/)를 참고한다.
- 팀 모델 가중치 `outputs/coco_4090_v3/best.pth`가 필요하다. 이 저장소의 v3 체크포인트를 사용한다.
- 기준 모델의 torchvision COCO_V1 가중치는 첫 분석 때 공식 PyTorch 서버에서 다운로드되어 로컬 캐시에 저장된다. 첫 실행에는 인터넷 연결과 시간이 필요하다.
- COCO 무작위 사진과 정답 박스를 가져오려면 허깅페이스에 인터넷 연결이 필요하다.

## 실행

저장소 루트에서 실행한다.

```bash
python compare_dashboard/server.py --open
```

브라우저가 자동으로 열리지 않으면 <http://127.0.0.1:8765/>에 접속한다. 서버를 실행한 창을 열어 둔다. 종료할 때는 창에서 Ctrl+C를 누른다.

같은 Wi-Fi의 휴대폰에서 사용하려면 별도 터미널에서 다음을 실행하고, 표시되는 접속 주소를 휴대폰 브라우저에 입력한다.

```bash
python compare_dashboard/server.py --phone
```

휴대폰용 주소는 실행할 때마다 새로 생성되며, 서버 창을 열어 둔 동안에만 사용할 수 있다. 연결되지 않으면 같은 네트워크 여부와 방화벽 설정을 확인한다. 휴대폰 연결은 로컬 네트워크의 HTTP 연결이므로 민감한 사진에는 사용하지 않는다. 카메라 버튼이 작동하지 않는 모바일 브라우저에서는 ‘휴대폰으로 촬영’ 버튼을 사용한다.

## 사용법

1. **사진 선택**, **카메라 촬영**, **휴대폰으로 촬영** 중 하나를 사용한다. 또는 **무작위 사진 가져오기**를 눌러 `Hyeon1222/COCO`의 `val2017.zip`에서 사진 한 장과 해당 정답 주석을 가져온다. 무작위 사진은 전체 ZIP을 내려받지 않고 필요한 부분만 읽는다. 첫 요청에는 주석을 읽는 데 시간이 더 걸릴 수 있다.
2. **표시할 최소 신뢰도**를 선택한다. 기본값은 50%이며 선택한 값 이상의 예측 박스만 화면에 표시한다. 모델 내부 출력의 점수 하한은 0.05이다. COCO 정답 박스는 신뢰도 필터의 영향을 받지 않는다.
3. **분석 장치**에서 CPU 또는 사용 가능한 CUDA GPU를 고른 뒤 **분석 시작**을 누른다. 호환 가능한 CUDA GPU가 없거나 CPU 전용 PyTorch가 설치된 환경에서는 GPU가 비활성화된다.
4. 두 모델의 박스와 객체 이름, 신뢰도, 분석 시간을 확인한다. 무작위 COCO 검증 사진에는 별도로 **COCO 정답 박스**가 보라색으로 표시된다. 점선은 COCO의 군집(`iscrowd`) 주석이다. 직접 선택하거나 촬영한 사진에는 정답 주석이 없다.
5. **성능 시각화** 탭에서는 팀의 2026-11-07 CPU 평가 결과를 확인한다. 추론 설정을 선택하면 세 모델의 mAP와 지연시간 중앙값(p50)이 바뀐다. 정확도는 val2017 5,000장, 지연시간은 별도 16장의 반복 측정 결과다.

## 결과를 읽을 때

- 사진 분석 시간은 각 모델에 동일한 이미지를 사용하고 한 차례 예열한 뒤 한 번 측정한다. 모델 불러오기와 파일 디코딩은 제외하고 모델 내부 전처리·추론·후처리는 포함한다. GPU를 사용할 때는 동기화 후 시간을 측정한다. 단일 측정값은 기기와 실행 조건에 따라 변하며, 성능 시각화의 과거 CPU 실험 결과와 직접 같은 조건은 아니다.
- 박스의 퍼센트는 모델의 클래스 신뢰도 점수이며 통계적 p-value가 아니다. 점수가 실제 정답 확률과 정확히 일치한다고 보장하지 않는다.
- 정답 박스는 COCO 검증 주석을 나타내며, 시각적 비교만 제공한다. 현재 화면은 이미지별 정밀도, 재현율 또는 IoU를 계산하지 않는다.
- 모델은 COCO 클래스에 대해 학습되어 있어, 그 밖의 대상을 놓치거나 잘못 분류할 수 있다.
